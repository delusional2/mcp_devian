# mcp_devian

Помощник для продажи адоптов на DeviantArt и Toyhouse. Следит за группами, аукционами и форумами, готовит сабмиты и отклики, а отправляет только после «го» в чате.

Работает на маке, пока он включён. Управляется из Claude через локальный MCP-сервер.

## Зачем

Рутина, от которой хочется избавиться:

- **DeviantArt.** После каждой публикации раскидывать работу по десятку групп и в каждой выбирать папку.
- **Toyhouse.** Профиль никто не смотрит, всё происходит на форуме. Приходится вручную листать LF-треды (где ищут адоптов) и треды продаж, чтобы откликнуться своим персом.
- **Toyhouse, персонажи.** Заводить персов неудобно: папки, подпапки, миры.
- **Покупки.** Следить за чужими аукционами, чтобы не пропустить интересное.

## Как работает

```
монитор (по расписанию) → дайджест → «вот 3 LF-треда под твоих персов»
        → черновик в чате → «го» / «поправь» / «скип»
        → отправка через MCP → журнал + лимиты
```

Главное правило: **без подтверждения ничего не публикуется.** Каждый сабмит и каждый отклик сначала показывается в чате целиком: куда, что, какой текст. Отправляется только после явного «го».

## Что выяснили про площадки

### DeviantArt

- **Официальный API жив.** Своё приложение регистрируется самостоятельно: OAuth 2.1 + PKCE, access-токен на 1 час, refresh-токен на 3 месяца. [Документация](https://deviantart.readme.io/docs/authentication).
- **Рассылка в группы есть в API.** У `POST /stash/publish` есть параметры `groups[]` и `group_folders[]`, папка указывается для каждой группы в том же порядке. Получается, новую работу можно отправить во все группы одним запросом ([stash/publish](https://deviantart.readme.io/reference/stash_publish.md)). У `/deviation/edit` по документации есть те же поля ([deviation/edit](https://deviantart.readme.io/reference/deviation_edit.md)). **Вживую это никто не проверял**, поэтому первый шаг фазы 2 — тест на 2–3 её группах.
- **Чего в API нет:** списка «мои группы», поиска групп, правил и лимитов групп. Список групп и пресеты ведём сами.
- **Лимиты задаёт каждая группа:** обычно до 10 сабмитов в день, отдельно по папкам. Если сабмит ушёл на голосование и решения нет 14 дней, он сгорает ([справка DA](https://www.deviantartsupport.com/en/article/how-do-group-admins-vote-on-submissions)).
- **Мониторинг групп работает без логина:** у каждой папки группы есть RSS. Порядок в нём не гарантирован, поэтому дедуп по `deviationid`.
- **Готовые юзерскрипты для массовой рассылки мертвы.** dev_group_list2 удалили с Greasy Fork 22.10.2026, и он уже не работал.

### Toyhouse

- **API для контента нет.** OAuth отдаёт только `/me`.
- **Cloudflare на каждой странице.** Не-браузеры получают 403, библиотеки-скрейперы сломаны. Поэтому читаем только через настоящий браузер с её логином, редко и спокойно.
- **Нужные доски:** [Adoption Center](https://toyhou.se/~forums/13.adoption-center), Design Marketplace, Art Marketplace. ID последних двух ещё проверить.
- **С 1 декабря 2026 действует новый Code of Conduct** ([анонс](https://toyhou.se/~forums/18.announcements/869575.th-october-2026-updates-new-code-of-conduct)). Спамом в нём считаются «repeated, irrelevant replies» и одинаковые объявления одного перса в разных местах. С сентября работает автоблок спама, уже залочено больше 500 аккаунтов. Отсюда жёсткие лимиты и дедуп.
- **Говорят, что запрещены тексты, написанные ИИ**, включая описания персов. Нужно прочитать CoC целиком. До этого отклики собираются только из её шаблонов, нейронка их не пишет.

### Safari

- **safaridriver** открывает чистую сессию без её логинов. Для нашей задачи бесполезен.
- **AppleScript** может выполнять JS в настоящем Safari, но из фоновых задач работает ненадёжно.
- **Итог:** Safari остаётся её браузером для жизни. Для автоматики заводим отдельный профиль Chrome (Playwright, `channel="chrome"`). Она один раз логинится в нём на DA и Toyhouse, дальше сессия живёт сама.

## Архитектура

| Часть | Чем |
|---|---|
| Язык | Python + [uv](https://docs.astral.sh/uv/) |
| Браузер | Playwright + установленный Chrome, отдельный persistent-профиль |
| DeviantArt | Официальный API (OAuth, токены в Keychain) + RSS папок групп |
| Toyhouse | Тот же браузерный профиль, чтение страниц форума |
| Хранилище | SQLite: `seen_items`, `groups`, `threads`, `characters`, `drafts`, `sent_log` |
| Расписание | launchd LaunchAgent (после сна догоняет пропущенное) |
| Уведомления | Telegram-бот и/или уведомления macOS |
| Интерфейс | Локальный stdio MCP-сервер для Claude Desktop / Claude Code |

### MCP-инструменты

Чтение:

- `list_new_adopts` — свежие адопты и аукционы по её фильтрам
- `list_lf_threads` — активные LF-треды, сматченные с её персами
- `list_groups` — её группы, папки, лимиты на сегодня

Подготовка черновика (ничего не отправляет):

- `prepare_group_submission` — куда и в какие папки уйдёт работа
- `prepare_reply` — отклик в тред по её шаблону
- `prepare_character` — карточка перса для Toyhouse

Отправка (только по `draft_id` уже показанного черновика):

- `submit_draft` — отправить черновик после «го»

Защита в `submit_draft`:

- без существующего черновика ничего не отправляется;
- один отклик в тред;
- один перс не больше чем в 2–3 тредах в сутки;
- на Toyhouse 5–10 откликов в день;
- случайные паузы между отправками;
- лимиты групп DA;
- при капче, челлендже или 429 всё останавливается и приходит уведомление.

## План

**Фаза 1. Мониторинг**

- [ ] DA: список групп, folderid папок, RSS раз в 30 мин, дедуп
- [ ] DA: классификатор лотов (OPEN/CLOSED, SB/AB, pts/$, OTA/BTA/YCH), фильтры по ключевым словам и бюджету
- [ ] Toyhouse: Chrome-профиль, первые страницы нужных досок раз в 30–60 мин, активность треда, LF или продажа
- [ ] Дайджест в Telegram / уведомления
- [ ] MCP-сервер с инструментами чтения

**Фаза 2. Отправка через чат**

- [ ] Регистрация приложения DA, живой тест `groups[]` на 2–3 группах
- [ ] Пресеты групп («аукционы», «points», …) и `submit_draft` для DA
- [ ] Каталог её персов, матчинг с LF-тредами, шаблоны откликов
- [ ] `submit_draft` для Toyhouse с лимитами

**Фаза 3. Органайзер персов на Toyhouse**

- [ ] Разобрать формы создания перса в залогиненной сессии
- [ ] Карточка адопта → пошаговое заполнение: картинки с кредитами, ownership, trade listing, подача в мир
