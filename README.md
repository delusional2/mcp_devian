# mcp_devian

Помощник для художницы, которая продаёт адоптов на DeviantArt и Toyhouse:

- следит за группами DeviantArt и форумами Toyhouse;
- находит лоты, которые она хочет купить, и треды, где ищут персов;
- подсказывает цену для её работ по рынку.

Живёт в приложении Claude на маке. Ничего не публикует.

## Установка

1. Скачать `mcp-devian-<версия>.mcpb` и открыть двойным кликом. Claude Desktop покажет окно установки, нажать «Установить». Первая установка занимает 1–3 минуты: Claude сам скачивает Python и всё нужное.
2. Написать Claude: «давай настроим помощника по адоптам». Можно выбрать **setup** в меню «+». Claude задаст вопросы и сам всё сохранит. Конфиги руками править не нужно.

Обновление: открыть новый `.mcpb` так же. Настройки и накопленные данные сохранятся: они лежат в `~/Library/Application Support/mcp_devian/`, а не в папке расширения.

Удаление: сначала сказать Claude «выключи фоновую проверку», потом удалить расширение в настройках Claude. Если удалить сразу, фоновая задача останется в системе. Она не сломается, просто будет тихо ничего не делать.

## Что можно просить в чате

- «что нового?» — свежие лоты с DA и живые LF-треды с Toyhouse;
- «проверь тойхаус сейчас»;
- «сколько поставить за нового дракона-мотылька на аукцион? думаю SB $25»;
- «как продаются мои работы?»;
- «добавь группу da-adopts, папки auctions и points adopts»;
- «включи проверку раз в 15 минут» / «выключи»;
- «скрой этот лот».

Если Claude спрашивает разрешение на инструменты чтения (`list_*`, `get_settings`, `market_forecast`…), можно выбрать «Разрешать всегда». Эти инструменты ничего не меняют.

## Как читается Toyhouse: два режима

У Toyhouse нет API, и на каждой странице стоит Cloudflare. Поэтому читать нужно настоящим браузером.

**bot — автоматический парсер** (по умолчанию).

- Как работает: свой отдельный Chrome-профиль, проверяет сам по расписанию, даже когда чат закрыт.
- Без входа видит только публичное. Чтобы войти, сказать «войди в аккаунт бота»: откроется окно, логин и пароль вводятся прямо на сайте, в чат их писать не нужно.
- Ограничение: Cloudflare иногда просит у бота галочку «я человек». Тогда приходит уведомление, и галочку нажимает она. Бот эту проверку не обходит.

**chrome — её обычный Google Chrome.**

- Как работает: когда она просит в чате, сервер открывает вкладку в её Chrome, забирает список тредов, закрывает вкладку и возвращает ту, что была открыта.
- Плюсы: она там уже залогинена, Cloudflare видит обычного посетителя.
- Ограничение: работает только по просьбе, в фоне Toyhouse не проверяется.
- Один раз нужно:
  1. В Chrome: меню **Вид → Разработчикам → Разрешить JavaScript из событий Apple** (в английском Chrome: View → Developer → Allow JavaScript from Apple Events).
  2. Когда macOS спросит, разрешить Claude управлять Google Chrome.
- Важно знать: оба разрешения действуют на все вкладки Chrome и на всё приложение Claude, а не только на этого помощника. Выключить: снять ту же галочку в Chrome и убрать Claude → Google Chrome в «Системные настройки → Конфиденциальность и безопасность → Автоматизация».

Другие запросы «Claude хочет управлять…» (Finder, System Events и т. п.) помощнику не нужны, их можно смело отклонять.

DeviantArt в обоих режимах читается без браузера, через RSS папок групп.

## Прогноз по рынку

Мониторинг копит лоты из отслеживаемых папок:

- стартовые цены (SB) аукционов и фикс-цены;
- тип лота и теги;
- когда лот появился и когда закрылся.

`market_forecast` находит похожие лоты по словам (вид, стиль) и показывает:

- обычный диапазон цен;
- сколько похожих сейчас открыто;
- какая доля закрывается и как быстро;
- где её цена среди похожих.

Ограничения честные: финальных ставок не видно, «закрыт» не всегда значит «продан», данные копятся с момента установки. Чтобы прогноз был точнее, стоит добавить пару крупных групп адоптов «только для рынка»: из них не приходят уведомления, но они дают цены.

Claude пересказывает прогноз бережно: диапазоны вместо приговоров и мягкие варианты вместо критики.

## Что выяснили про площадки

### DeviantArt

- **Мониторинг групп работает без логина.** У каждой папки группы есть RSS: `backend.deviantart.com/rss.xml?type=deviation&q=gallery:<группа>/<номер>`. Порядок в нём не гарантирован, поэтому дедуп идёт по `deviationid`. robots.txt просит `Crawl-delay: 1`, поэтому между лентами пауза 1.5–3.5 с.
- **Рассылка в группы есть в официальном API.** У `POST /stash/publish` есть параметры `groups[]` и `group_folders[]` ([stash/publish](https://deviantart.readme.io/reference/stash_publish.md)). Вживую не проверялось, это задача фазы 2.
- **Лимиты задаёт каждая группа:** обычно до 10 сабмитов в день. Если сабмит ушёл на голосование и решения нет 14 дней, он сгорает ([справка DA](https://www.deviantartsupport.com/en/article/how-do-group-admins-vote-on-submissions)).

### Toyhouse

- **API для контента нет.** OAuth отдаёт только `/me`.
- **Cloudflare на каждой странице.** HTTP-клиенты и Chrome без окна не пускают.
- **Доски:** [Adoption Center](https://toyhou.se/~forums/13.adoption-center) (13), Design Marketplace (5866), Art Marketplace (71). Номера сняты с меню форума.
- **С 1 декабря 2026 действует новый Code of Conduct** ([анонс](https://toyhou.se/~forums/18.announcements/869575.th-october-2026-updates-new-code-of-conduct)). Спамом считаются повторяющиеся отклики и одинаковые объявления одного перса. С сентября работает автоблок. Отсюда правило для будущей фазы 2: отклики только после её «го», с лимитами.

### Claude Desktop

Проверено на 01.11.2026:

- поле `instructions` MCP-сервера модели не передаётся, поэтому правила настройки и тон живут в описаниях инструментов;
- формы с вопросами (elicitation) пока не показываются;
- вызов инструмента обрывается примерно через 60–240 с, поэтому проверка идёт в фоне: `check_now` ждёт до 45 с, остальное узнаётся через `check_status`.

## Устройство

| Часть | Чем |
|---|---|
| Установка | `.mcpb` с `server.type: "uv"`: Claude Desktop сам ставит uv, Python и зависимости по `uv.lock` |
| Настройки | `settings.json` в папке данных, заполняются через `update_settings` по ответам в чате |
| DeviantArt | RSS папок групп, её галереи и выбранных художников |
| Toyhouse | её Chrome через Apple Events (`her_chrome.py`) или Playwright с отдельным профилем (`toyhouse.py`) |
| Хранилище | SQLite в папке данных |
| Фон | launchd LaunchAgent, включается из чата (`set_background_checks`) |
| Уведомления | macOS и (по желанию) Telegram |
| Прогноз | `market.py`: перцентили цен похожих лотов, доля и скорость закрытия |

## Разработка

```bash
uv sync --group dev
```

```bash
uv run --group dev pytest -q
```

Собрать установщик (нужны uv и node):

```bash
./scripts/build-mcpb.sh
```

Для Claude Code в этой папке сервер подхватывается из `.mcp.json`. Команды для терминала: `uv run mcp-devian --help`.

Telegram: положить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `~/Library/Application Support/mcp_devian/.env` и попросить Claude включить уведомления в Telegram.
